# 0.3.1 — 2026-09-18

## Changed

- **`mcp-error-triage`** reads the input's `recoveryHint` and sends it as `error.recovery_shown_to_caller`; `message_clarity` judges it together with `error.shown_to_caller`, since the framework shows a caller both. On a three-day window the opaque set went from 18 patterns, 14 of which had shown the caller a usable hint, to 4 that carried none.
- **`origin_disagrees`** needs 0.75 confidence when Jev's call is `server`, and still 0.6 otherwise. Every `server` call against an `input` label in a verified review was a caller's SQL error.

## Added

- **`docs/findings.md`**: the recovery-hint measurement, and which disagreement direction produced verified findings.
- **`samples/mcp-errors.jsonl`**: a record whose message is opaque alone and clear with its `recoveryHint`.
