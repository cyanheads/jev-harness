# 0.2.0 — 2026-09-17

## Added

- **`jev calibrate --rows <rows.jsonl> --truth <truth.jsonl> [--bins N]`** prints a reliability table, accuracy, Brier score, and expected calibration error for every Choice and Noul that has a truth value. Truth lines are `{"id", "truth": {"<question>": "<option>" | boolean}}`.
- **`jev stability <rows.jsonl> <rows.jsonl>...`** reports the largest run-to-run difference per question over records present in every run, plus Choice flips.
- **`src/analysis/`** (`calibrate`, `stability`, renderers) exported from the package root and as `jev-harness/analysis`.
- **`docs/findings.md`**: measured stability, calibration by answer type, and what a real error-triage run showed.
- **`docs/ideas/`**: write-ups for a literal-client probe of MCP tool descriptions and for measuring tool-search ranking.

## Changed

- **`mcp-error-triage`** escalates when the probability on the top two severity levels sums to 0.8, replacing the score-and-confidence gate; adds a derived `opaque_message`; drops the `dx_gap` question, which was true of most input errors.
