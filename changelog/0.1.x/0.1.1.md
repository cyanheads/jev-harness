# 0.1.1 — 2026-09-17

## Added

- **Package `exports`** (`.`, `./client`, `./questions`, `./experiments`, `./input`, `./run`) and `src/index.ts`, so another repo can `bun link jev-harness` and import the harness as a library.

## Changed

- **`NoulQuestion.criteria`** now requires both `true` and `false` when present. OpenRouter's `/api/alpha/decisions` returns 400 for a one-sided criteria object; `stringifyEntries` always sends both sides.

## Fixed

- **Shell-exported `OPENROUTER_API_KEY` shadowing `.env`** is documented in `CLAUDE.md` and the README with the diagnosis and bypass.
