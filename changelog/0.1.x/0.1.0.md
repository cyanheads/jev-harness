# 0.1.0 — 2026-09-17

## Added

- **`JevClient`** — one `ask(state, questions)` against OpenRouter's `/api/alpha/decisions` (default) or TypeSafe's `/v1/systemone`; retries 429/5xx honoring `retry-after`, validates answers against the declared questions, reports tokens, cost, and latency per call.
- **`choice` / `score` / `noul`** builders with `AnswersFor<Qs>` answer-type inference and Zod wire schemas.
- **`defineExperiment`** — questions + `state(record)` mapper + optional `derive(answers, record)` policy, one file per experiment under `experiments/`.
- **`bin/jev.ts`** — `run` (JSONL rows + `.report.txt`, `--dry-run`, `--limit`, `--concurrency`, `--keep-input`, `--keep-state`), `ask` (ad-hoc questions from flags), `list`.
- **Input loader** for JSONL, JSON, text files, directories, and stdin.
- **Experiments** `ticket-routing` and `mcp-error-triage` with sample inputs in `samples/`.
- **Docs** — `docs/jev-prompting.md`, `docs/decisions.md`, `docs/llm-comparison.md` (planned comparison mode).
