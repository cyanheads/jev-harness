# 0.5.0 — 2026-09-23

## Added

- **Per-record questions.** `Experiment.questions` can be a function of the record (`QuestionsBuilder`), for options drawn from the record such as a query's candidate tools; `questionsFor(experiment, record)` resolves either form. Still one request per record.
- **`experiments/tool-ranking.ts`** with `samples/tool-queries.jsonl`: a per-record Choice over each request's candidate tools, `derive` reporting the expected tool's `rank`, `hit_at_1`, and `hit_at_3`.
- **`jev compare <before> <after>`** (`compare`, `renderComparison`): joins two runs on id and reports per question the records whose answer changed, the mean shift for a Noul or Score, and the changed records, largest difference first.
- **Threshold sweep in `calibrate`** (`Cutoff`, `QuestionCalibration.sweep`): at cutoffs 0.1 to 0.95, the share of rows kept, their accuracy (Noul: precision), and the share of right answers (Noul: true rows) kept.
- **Score calibration.** A truth value can be a level index; a Score is judged by its most probable level and reports `meanLevelError`.
- **`jev run --resume <rows.jsonl>`**: sends only the records the rows file lacks, appends to it, and rewrites its report over all rows.
- **Report notes**: over 20 rows or more, a `!` line under a question when one option or level takes 90% of rows or a Noul is above 0.5 on 75%.

## Changed

- **`Experiment.questions`** is typed `Qs | QuestionsBuilder<Qs, R>`; code that read it as an object calls `questionsFor` instead.
- **Rows** are appended to the rows file one synchronous line at a time instead of through a buffered writer, so a crash keeps every finished row.
- **Report**: a question answered in only some rows says so and takes its shares over those rows; option lists past 15 entries collapse into one line.
- **`truthLineSchema`** accepts non-negative integers.
