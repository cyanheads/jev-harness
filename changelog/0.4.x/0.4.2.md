# 0.4.2 — 2026-09-23

## Fixed

- **`retryDelayMs`** treats a blank `retry-after` as absent and backs off. `Number('')` is 0, so a blank header retried with no delay.
- **`jev ask`** rejects a question id used twice, including a written id that matches an auto-assigned `q<N>`, and a `--choice` or `--score` list that repeats an entry. The later question used to replace the earlier one, and repeated choice options collapsed into one.
- **The run report** labels a Score level written as a structured entry with its JSON instead of `[object Object]`.

## Changed

- Casts and impossible-state fallbacks in the report and stability code give way to inferred type predicates; output is unchanged.
