# 0.4.3 — 2026-09-23

## Fixed

- **Null entries.** OpenRouter answers a null instruction, Score level, or Noul side with a 400 and accepts `null` only as a Choice option value. `stringifyEntries` encoded a null in those positions as the string `"null"`, which OpenRouter accepted as the question text. `ChoiceQuestion`, `ScoreQuestion`, `NoulQuestion`, and the `choice` / `score` / `noul` builders now take `NonNullable<Entry>` there, so the mistake is a compile error. Choice option values still take `null`.
