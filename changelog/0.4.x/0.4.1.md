# 0.4.1 — 2026-09-23

## Added

- **`readJsonl`**, exported from `jev-harness/input`: reads a JSONL file and names the path and line of a line that is not JSON. `jev calibrate` and `jev stability` read rows and truth files through it.

## Changed

- **`choice()`** throws on zero options or more than 255, the API's limit, like `score()` does for its level count.
- **`retryDelayMs`** reads a `retry-after` HTTP date as well as delay-seconds; takes an optional `now`.

## Fixed

- **`runExperiment`** stops handing out records once `onRow` or `onFailure` throws. Other workers used to keep calling Jev, and the CLI kept writing rows to a file it had already closed.
- **`jev run` progress** counts failures, so a run with failures reaches N/N.
- **`jev run` output files** carry milliseconds in the timestamp. Two runs started in the same second (repeated runs for `stability`) wrote to one file.
- **A JSONL or `.json` input that does not parse** names the file and line instead of a bare `JSON Parse error`.
- **A connection that fails on every attempt** reports the provider and attempt count, with the original error as `cause`.
