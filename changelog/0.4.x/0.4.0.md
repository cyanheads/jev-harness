# 0.4.0 — 2026-09-18

## Changed

- **`calibrate`** returns `{ questions, skipped }` instead of an array; `renderCalibration` takes that object. `skipped` counts, per question, the truth values it could not score: no such answer in the row, a truth of the wrong kind for the answer type, or a Choice truth that names no declared option. Those used to shrink `n` without a word.
- **`loadRecords`** throws when an input's record ids repeat. `calibrate`, `stability`, and readers of the rows file all join on `id`, and a repeat overwrote one row with another.
- **`runExperiment`** rejects when `onRow` throws. The record used to land in both `rows` and `failures`.
- **`retryDelayMs`** caps a `retry-after` at one minute.
- **`--dry-run`** resolves provider and model as the real call does: `JEV_PROVIDER` and `JEV_MODEL` on `run`, plus `--provider` and `--model` on `ask`, which ignored both.
- **CLI errors** print the message and exit 1, without a stack trace.

## Added

- **`truthLineSchema`**, exported from `jev-harness/analysis`: the Zod schema `jev calibrate` parses each truth line with. A numeric `id` is compared as a string, like a row's.
- **`Calibration`** type.
- **`bin/jev.test.ts`**: flag validation and dry-run provider resolution, run against the CLI itself.

## Removed

- **`summarizeRows`**, which nothing called.

## Fixed

- **`--concurrency`, `--limit`, `--bins`** reject anything but a positive integer. A non-numeric `--concurrency` started zero workers and exited 0 with no rows; a non-numeric `--limit` reported "no records".
- **`--provider`** rejects a name that is not a provider, instead of crashing on the lookup.
- **408 and 504** retry, like the other transient statuses.
- **A 2xx response that is not the documented shape** (an error envelope, markup from the edge) fails with the offending paths and the start of the body, instead of a Zod issue dump.
